# مزود AI Gateway (Vercel) — الحلقة الرابعة في السلسلة

هذه الوثيقة هي عقد إضافة AI Gateway: ما أُضيف، وما لم يتغير، وكيف يُتحقق منه، وكيف يُعكس.

**المبدأ الحاكم (نفس نمط NIM):** المزود **اختياري بحكم التكوين** — غياب
المفتاح = غياب المزود، فيُتخطى صامتًا ولا يتغيّر أي مسار قائم.

---

## 1) السلسلة بعد الإضافة

```
ENABLE_AI_AGENT != "true"  ⇒  رد محلي فوري (بدون شبكة)

ENABLE_AI_AGENT = "true"   ⇒  Gemini ← Groq ← NVIDIA NIM ← AI Gateway ← الرد المحلي
```

Groq وNVIDIA NIM وAI Gateway يدعمون الأدوات (`supportsTools`)؛ Gemini
والمحلي يبقيان على مسارهما النصي حرفيًا.

---

## 2) المتغيرات

| المتغير | القيمة | الافتراضي | الحدود المفروضة |
|---|---|---|---|
| `AI_GATEWAY_API_KEY` | مفتاح البوابة من Vercel Dashboard ← AI Gateway ← API Keys (بصيغة `vck_…`) | غائب ⇒ المزود غير متاح ويُتخطى | — |
| `AI_GATEWAY_BASE_URL` | رابط البوابة (سحابي أو مخصّص) | `https://ai-gateway.vercel.sh/v1` | **https فقط**؛ أي مخطط آخر ⇒ المزود غير متاح |
| `AI_GATEWAY_MODEL` | اسم النموذج بصيغة البوابة `creator/model-name` | `openai/gpt-4o-mini` | — |
| `AI_PROVIDER_ORDER` | ترتيب السلسلة (اختياري) | `gemini,groq,nvidia-nim,ai-gateway,local` | الأسماء غير المعروفة تُتجاهل، و`local` مثبّت في النهاية دائمًا |

## 3) ما أُضيف (ملفات)

| العنصر | الملف | الوصف |
|---|---|---|
| مزود AI Gateway | `src/lib/ai/providers/ai-gateway.ts` | واجهة متوافقة مع OpenAI عبر العميل الموحّد، مع دعم الأدوات |
| الترتيب | `src/lib/ai/chain-order.ts` | `ai-gateway` اسم معروف، وفي الترتيب الافتراضي قبل `local` |
| المحرك | `src/lib/ai/agent-engine.ts` | المزود مسجّل في حوض المزودين الافتراضي |
| الصادرات | `src/lib/ai/index.ts` | `AiGatewayProvider` والثوابت والدوال المساعدة |
| حجب المفتاح | `src/lib/errors/index.ts` | نمط `vck_…` ⇒ `[REDACTED_AI_GATEWAY_KEY]` |
| فحص الحزمة | `scripts/scan-bundle-secrets.mjs` | `AI_GATEWAY_API_KEY` ضمن أسماء أسرار الخادم |
| الاختبارات | `tests/ai-gateway.test.ts` | سياسة الرابط، عقد الطلب، الأدوات، الحجب، السلسلة الصامتة |

> **لا هجرات قاعدة بيانات، ولا تغيير في أي جدول أو عقد API قائم.**
> استدعاءات المزود تتم من الخادم فقط (داخل `/api/chat`)، فلا حاجة لأي
> تغيير في CSP — بنفس سابقة NIM (مضيفه غير مذكور في `connect-src`).

---

## 4) ضمانات أمنية

- **اختياري صامت:** بلا مفتاح لا يوجد المزود في السلسلة إطلاقًا.
- **https إلزامي** لأي رابط مخصّص، فلا يمر مفتاح على قناة غير مشفّرة.
- **حجب الأسرار:** نمط `vck_…` مضافة إلى `redactSecrets`، وأي رسالة خطأ
  تمر عبرها قبل السجل؛ والترويس `Bearer` محجوب أصلًا بنمط عام.
- **لا سطح جديد:** لا مسار HTTP جديد، والتنفيذ داخل دورة الوكيل فقط.
- **الأدوات كما هي:** نفس بوابات MCP السبع من المرحلة الثانية بلا توسيع.

---

## 5) صفر كسر — مصفوفة السلوك

| ENABLE_AI_AGENT | المفتاح | السلوك |
|---|---|---|
| غائب/`false` | أي قيمة | رد محلي فوري — مطابق لما قبل الإضافة حرفيًا |
| `true` | بلا مفاتيح | Gemini ⇒ Groq ⇒ NIM (غير متاح) ⇒ Gateway (غير متاح) ⇒ محلي |
| `true` | Gateway وحده | نص من البوابة، أو محلي عند فشلها — بلا 500 |
| `true` | `AI_PROVIDER_ORDER` قديم بلا `ai-gateway` | يُحترم حرفيًا؛ البوابة خارج السلسلة المطلوبة |

## 6) التحقق القابل لإعادة التشغيل

```bash
npm test          # يتضمن: ai-gateway (سياسة الرابط + عقد OpenAI + الأدوات + الحجب + السلسلة)
npm run lint
npm run typecheck
npm run security:gates
npm run build
```

ثم على بيئة الإنتاج:

1. بدون `AI_GATEWAY_API_KEY`: `source` في استجابة `/api/chat` لا تكون
   `ai-gateway` أبدًا (المزود غير موجود في السلسلة).
2. بالمفتاح: رسالة عادية تُرجع `source: "ai-gateway"` عند غياب مفاتيح
   المزودين الأسبق، أو عند ترتيب يقدّمه عبر `AI_PROVIDER_ORDER`.
3. في السجلات: أي فشل يظهر كمقياس `ai_provider_failure` مع رسالة محجوبة.

---

## 7) التراجع (Rollback)

العكس هنا إعداد لا كود: احذف `AI_GATEWAY_API_KEY` وأعد النشر — تخرج
البوابة من السلسلة تلقائيًا لأن `isAvailable()` تعتمد على وجود المفتاح.

- لا هجرات، لا تغيير في المخطط، لا تغيير في عقود API.
- قوائم `AI_PROVIDER_ORDER` القديمة التي لا تذكر `ai-gateway` تبقى صالحة
  حرفيًا (الاسم الجديد اختياري في القائمة لا إلزامي).

---

## 8) المراجع

- نقطة النهاية: `POST https://ai-gateway.vercel.sh/v1/chat/completions`
  (متوافقة مع OpenAI: `tools` + `tool_choice: "auto"` للأدوات).
- صيغة النماذج: `creator/model-name` (مثل `openai/gpt-4o-mini`).
- العميل الموحّد: `src/lib/ai/tools/openai-compatible.ts` (مهلة 20 ثانية).
