# المرحلة الثانية: مزود NVIDIA NIM اختياري + طبقة MCP محكومة

هذه الوثيقة هي عقد المرحلة الثانية: ما أُضيف، وما لم يتغير، وكيف يُتحقق منه، وكيف يُعكس.

**المبدأ الحاكم:** أي قدرة جديدة تُضاف **خلف علم ميزة مستقل**، وتكون **اختيارية بحكم التكوين** (غياب المفتاح = غياب المزود)، ولا تغيّر أي مسار قائم عند الإغلاق.

---

## 1) ما أُضيف

| العنصر | الملف | الوصف |
|---|---|---|
| مزود NVIDIA NIM | `src/lib/ai/providers/nvidia-nim.ts` | واجهة متوافقة مع OpenAI، مفتاح `NVIDIA_NIM_API_KEY` أو `NVIDIA_API_KEY`، رابط NIM سحابي أو داخلي **https فقط** |
| عميل موحّد | `src/lib/ai/tools/openai-compatible.ts` | عقد واحد للرسائل والأدوات يخدم Groq وNIM، مع مهلة نقل مركزية (20 ثانية) وحجب أسرار موحّد |
| دورة الأدوات المحدودة | `src/lib/ai/tools/run-tool-loop.ts` | سقف دورات = سقف الاستدعاءات + 1، والدور الأخير بلا أدوات لإجبار نص نهائي |
| طبقة MCP المحكومة | `src/lib/ai/mcp/` | سجل أدوات + سياسة + تحقق + مهلة + اقتصاص + تدقيق |
| أدوات المتجر | `src/lib/ai/mcp/tools/store.ts` | `search_products`، `lookup_faq`، `shipping_estimate`، `store_info` — كلها **قراءة فقط** |
| مانيفست إداري | `src/app/api/admin/mcp/tools/route.ts` | عرض الأسماء والسياسة فقط؛ لا يوجد أي مسار HTTP لتنفيذ أداة |
| حجب مفاتيح NVIDIA | `src/lib/errors/index.ts` | نمط `nvapi-…` ⇒ `[REDACTED_NVIDIA_KEY]` |
| مقاييس الأدوات | `src/lib/observability/metrics.ts` | `mcp.calls` / `mcp.errors` / `mcp.avg_ms` / `mcp.by_tool` / `mcp.by_status` |

> **لا هجرات قاعدة بيانات في هذه المرحلة، ولا تغيير في أي جدول أو عقد API قائم.**

## 2) الأعلام والمتغيرات

| المتغير | القيمة | الافتراضي | الحدود المفروضة |
|---|---|---|---|
| `ENABLE_AI_AGENT` | `true` لتشغيل المحرك النمطي | معطّل | من المرحلة الأولى — لم يتغير |
| `NVIDIA_NIM_API_KEY` أو `NVIDIA_API_KEY` | مفتاح NIM (اختياري) | غائب ⇒ المزود غير متاح ويُتخطى | — |
| `NVIDIA_NIM_BASE_URL` | رابط NIM سحابي أو مستضاف داخليًا | `https://integrate.api.nvidia.com/v1` | **https فقط**؛ أي مخطط آخر ⇒ المزود غير متاح |
| `NVIDIA_NIM_MODEL` | اسم النموذج | `meta/llama-3.3-70b-instruct` | — |
| `ENABLE_MCP_TOOLS` | `true` لفتح طبقة الأدوات | معطّل | غير `true` ⇒ صفر أدوات وصفر تنفيذ |
| `MCP_ALLOWED_TOOLS` | قائمة أسماء مفصولة بفواصل | المجموعة الافتراضية (4 أدوات) | ما ليس في القائمة غير مرئي وغير قابل للتنفيذ |
| `MCP_ALLOW_WRITE_TOOLS` | `true` للسماح بأدوات كاتبة | معطّل | الأدوات الكاتبة تُرفض في التسجيل نفسه |
| `MCP_MAX_CALLS_PER_REQUEST` | سقف استدعاءات لكل رسالة | `3` | 0–8 (القيمة 0 تمنع التنفيذ) |
| `MCP_TOOL_TIMEOUT_MS` | مهلة الأداة الواحدة | `4000` | 300–10000 |
| `MCP_MAX_RESULT_CHARS` | حد مخرجات الأداة إلى الموديل | `4000` | 200–20000 |

كل الأرقام تُقيَّد رياضيًا: قيمة بيئية خاطئة أو ضخمة لا توسّع الحد أبدًا (اختبار يثبت ذلك).

## 3) السلسلة بعد المرحلة الثانية

```
ENABLE_AI_AGENT != "true"  ⇒  رد محلي فوري (بدون شبكة)

ENABLE_AI_AGENT = "true"   ⇒  Gemini ← Groq ← NVIDIA NIM ← الرد المحلي
                                   │
                                   └─ عند ENABLE_MCP_TOOLS = true **و** طلب الأدوات **و** مزود يدعمها:
                                      دورة أدوات محدودة عبر McpToolRegistry
                                      (اسم مسموح + وسائط صحيحة + مهلة + سقف + اقتصاص + تدقيق)
```

Groq وNVIDIA NIM يدعمان الأدوات (`supportsTools`)؛ Gemini والقارئ المحلي يبقيان على مسارهما النصي حرفيًا.

---

## 4) بوابات الطبقة المحكومة (بالترتيب)

1. **علم الميزة** `ENABLE_MCP_TOOLS` — غيابه يوقف كل شيء.
2. **القائمة المسموح بها** — الاسم غير المذكور غير مرئي، واستدعاؤه يُرفض.
3. **سقف الاستدعاءات** لكل رسالة مستخدم (Budget لكل طلب).
4. **تحقق الوسائط** بعقود zod صارمة (`.strict()` ⇒ رفض أي حقل غير معروف).
5. **مهلة مركزية** بـ `AbortSignal` + سقف زمني مفروض من الطبقة لا من الأداة.
6. **اقتصاص المخرجات** إلى الحد المركزي قبل إعادتها للموديل.
7. **تدقيق**: مقياس لكل استدعاء (`tool`، `status`، `duration_ms`) وسطر سجل JSON **بلا وسائط ولا مخرجات ولا أسرار**.

أي رفض يُعاد للموديل كنتيجة MCP (`isError: true`) لا كاستثناء، فلا يسقط الطلب ولا يظهر 500 للعميل.

## 5) ضمانات أمنية

- **قراءة فقط افتراضيًا:** لا أداة تلمس الطلبات أو بيانات العملاء (لا هاتف، لا عنوان، لا سجل طلبات)، وأي أداة كاتبة تُرفض في التسجيل حتى تُفعَّل بوابة مستقلة.
- **لا سطح تنفيذ جديد:** لا يوجد أي مسار HTTP يستدعي أداة؛ التنفيذ يحدث فقط داخل دورة الوكيل. مانيفست الإدارة للعرض فقط.
- **https إلزامي** لأي رابط NIM مخصّص، فلا يمر مفتاح على قناة غير مشفّرة.
- **حجب الأسرار:** نمط `nvapi-…` مضافة إلى `redactSecrets`، وأي رسالة خطأ تمر عبرها قبل السجل.
- **حدود معلنة:** الموديل يرى الحقول الأربعة فقط من كل أداة (اسم/وصف/مخطط/سياسة)، وما يخرج من الطبقة مقتص ومحصّى.

## 6) صفر كسر — مصفوفة السلوك

| ENABLE_AI_AGENT | ENABLE_MCP_TOOLS | المفتاح | السلوك |
|---|---|---|---|
| غائب/`false` | أي قيمة | أي قيمة | رد محلي فوري — مطابق لما قبل المرحلة الثانية حرفيًا |
| `true` | غائب/`false` | بلا مفاتيح | Gemini ⇒ Groq ⇒ NIM (غير متاح) ⇒ محلي — نفس المسار النصي القديم |
| `true` | غائب/`false` | Gemini أو Groq | نص كما في المرحلة الأولى حرفيًا (لا تُستدعى دورة أدوات) |
| `true` | `true` | مزود يدعم الأدوات | دورة أدوات محدودة، ثم نص نهائي |
| `true` | `true` | مزود لا يدعم الأدوات | مساره النصي القديم بلا تغيير |
| `true` | `true` | فشل الدورة | تسليم صامت للمزود التالي، وإن فشل الكل ⇒ الرد المحلي |

## 7) التحقق القابل لإعادة التشغيل

```bash
npm ci
npm run lint
npm run typecheck
npm run security:gates
node scripts/sync-migrations.mjs --check
npm run routes:inventory
npm test          # يتضمن: mcp-tools، agent-tools، nvidia-nim، mcp-route
npm run build
```

ثم على بيئة الإنتاج:

1. بدون `ENABLE_MCP_TOOLS`: `GET /api/admin/mcp/tools` ⇒ **404** (النقطة لا تكشف نفسها).
2. بـ `ENABLE_MCP_TOOLS=true` وبدون جلسة ⇒ **401**.
3. بجلسة إدارة ⇒ **200** مع قائمة الأدوات وسياسة الحدود فقط.
4. في سجل التشغيل: أسطر `mcp_tool_call` بلا وسائط ولا مخرجات.

## 8) التراجع (Rollback)

العكس هنا إعداد لا كود: احذف `ENABLE_MCP_TOOLS` (أو اجعله `false`) و/أو احذف مفتاح NIM وأعد النشر.

- لا هجرات، لا تغيير في المخطط، لا تغيير في عقود API، ولا بيانات يُعاد إنشاؤها.
- إزالة `NVIDIA_NIM_API_KEY` تُخرج NIM من السلسلة تلقائيًا لأن `isAvailable()` تعتمد على وجود المفتاح.

## 9) الخطوة التالية (المرحلة الثالثة — RAG)

الاسترجاع سيُبنى على **نفس الركيزة**: أداة قراءة فقط إضافية (`search_knowledge`) تُسجَّل في `McpToolRegistry`،
فتورث تلقائيًا كل البوابات السبع (علم ميزة، سماح، سقف، تحقق، مهلة، اقتصاص، تدقيق) بلا مسار جديد ولا سطح تنفيذ جديد.
