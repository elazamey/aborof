## المرحلة 1 — مسار القواعد (أول كود بعد الدمج)

**النطاق المغلق** (من رسالة الرؤية — البنود 1–13 و21–23):

1. طبقة السمات: `src/lib/catalog/attributes.ts` (بيانات مُصدَرة + عقد zod) —
   لا هجرة قاعدة في المرحلة 1 (السمات تُقرأ مع الكود وتُختبَر معه).
2. البحث بالمشكلة + «اختَر لي» (3 أسئلة: ماذا تنظف؟ ما المشكلة؟ الميزانية؟)
   ← `الأنسب / بديل اقتصادي / الأقوى`، كل توصية بسبب صريح (✓ سطح ✓ مشكلة
   ✓ ميزانية ✓ حجم).
3. المقارنة (حتى 3 منتجات) + سعر الوحدة المحسوب (ج/لتر، ج/كجم، ج/قطعة).
4. «البديل الأرخص» من البيانات (لا تخمين) + «لا تدعني أشتري الخطأ»
   (تحذير عدم-تطابق السطح قبل الإضافة للسلة).
5. صفحات المنتج الغنية (مناسب لـ/غير مناسب لـ/الاستخدام/الجرعة/التحذيرات)
   + «❌ لا نعرف» الصريح عند غياب السمة.
6. السلال الجاهزة (المطبخ/الحمام/الغسيل/الأرضيات) بزر «أضف المجموعة».
7. إعادة الطلب الأخير + مراجع واتساب بالمنتج (`#p4 × 2` تُحَلّ للمنتج).

**بوابات القبول المُرمَّزة:** اختبارات تغطية السمات (كل منتج: حجم + سعر-وحدة
+ مفردات مغلقة + إحالات `id` موجودة) · اختبارات حتمية للتوصية (مدخلات ثابتة
⇒ مخرجات ثابتة + سبب لكل توصية) · لا أي `500` خام في المسار الجديد ·
ميزانية أداء (لا مكتبات جديدة ثقيلة — `next/bundle` يُراجَع في الـ PR).
